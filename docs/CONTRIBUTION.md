# How to Contribute

Use the following checklist:

- [ ] Add acceptance tests
- [ ] Implement changes (If it's a UI task create a design with stitch first)
- [ ] Add unit tests
- [ ] Add playwright tests
- [ ] Update documentation as necessary
- [ ] Before committing, run tests, cargo clippy and other linters (see `docs/testing.md` for the test layers and platform prerequisites)

Any development should happen on a new branch and a pull request should be opened for it. Use conventional commits.
